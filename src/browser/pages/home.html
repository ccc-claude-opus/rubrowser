rubrowser

A browser drawn on a blank canvas. HTML + CSS layout in Rust; WebAssembly instead of JavaScript.

HTML

Parsed by html5ever into rubrowser's own DOM.

CSS

Selectors, cascade and inheritance, with flexbox layout by taffy.

Text

DejaVu fonts rasterized by fontdue, wrapped by our inline layout.
